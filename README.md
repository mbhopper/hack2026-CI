# Последний круг

Пиксельный 2D-детектив по кейсу банка «Центр-инвест»: гонщик погибает на трассе, игрок-детектив ищет убийцу.

Сейчас в репозитории: главная страница, вход и регистрация, вступительная катсцена, три локации с ходьбой детектива по клику выбор подозреваемого, допросы и финал с обвинением.

## Как устроена игра

1. **Катсцена** (`/intro`, ~95 секунд, 12 сцен). Рисуется на одном canvas 320×180 и масштабируется целым множителем, поэтому пиксели остаются чёткими. Стиль тот же, что у листов персонажей: чиби, тёмный контур `#0b0f0e`, свет сверху слева, квантованный свет и виньетка. Механики, детектив и «пятый механик» — PNG-листы (`src/assets/characters/`, `src/assets/cutscene/`), болиды и обломки — пиксельные карты в коде (`src/game/cars.ts`), фоны процедурные с кешем (`src/game/scenery.ts`, `src/game/lighting.ts`). Звуки катсцен синтезируются Web Audio (`src/game/audio.ts`). На телефоне кадр растягивается на ширину экрана, в вертикальной ориентации диалоги идут под кадром. Esc — пропустить, пробел — пауза.
2. **Локации** (`/locations`). После катсцены — меню из трёх локаций: место аварии, бокс №7 и VIP-ложа (`/locations/:id`). Детектив идёт туда, куда кликнули (поиск пути — `src/game/pathfinding.ts`). Когда он подходит к улике, над ним появляется «!» и кнопка «Осмотреть» (или клавиша E). Дождь идёт только на месте аварии. В VIP-ложе за стойкой бармен: с ним можно поговорить (кнопка «Поговорить» или E), разговор идёт так же, как допрос. Листок на столике открывается только после вопроса бармену о спонсоре. Кнопка «К подозреваемым» в меню открывается, когда осмотрены все десять пунктов: девять улик и разговор с барменом. Данные локаций — `src/game/locations/`, тексты улик — `src/game/story.ts`.
3. **Выбор подозреваемого** (`/suspects`). Стрелки ◀ ▶ (или ← → на клавиатуре) листают пилота №22, механика и спонсора, под портретом кнопка «Допросить».
4. **Допрос** (`/suspects/:id`). Детектив выбирает вопросы, ответы печатаются посимвольно (щелчок, пробел или Enter — дальше), портрет подозреваемого меняет эмоцию по ходу ответа. Некоторые вопросы открываются только после других. Важное попадает в блокнот «Показания». Вопросы и ответы — `src/game/dialogues.ts`.
5. **Обвинение** (`/accuse/:id`). Когда всем подозреваемым заданы все вопросы, на экране подозреваемых появляется кнопка «Назвать убийцу». Выбранный входит в комнату допросов (вид сверху), запрыгивает на стул напротив детектива, они говорят (катсцена на том же движке, сценарий — `src/cutscene/accusation.ts`, комната и документы — `src/game/interrogationRoom.ts`). Пилот и механик заканчиваются надписью «Ты ошибся.» и возвратом на главную под грустную тему; спонсор — папкой на столе, печатью «Дело раскрыто», финальной музыкой и титрами, в которых по шагам рассказано, как спонсор убил пилота.

Сценарий катсцены — массив сцен в `src/cutscene/script.ts`: у каждой есть длительность, функция отрисовки, звуковые события и текст поверх кадра. Тексты улик и подозреваемых — в `src/game/story.ts`. Прогресс (просмотрена ли катсцена, какие улики найдены) пока хранится в `localStorage` (`src/game/progress.ts`).

## Музыка

Фоновая музыка играет на всех страницах и плавно меняется при переходах (`src/game/music.ts`, на странице — хук `useMusic`):

| Где | Трек |
| --- | --- |
| Главная, вход, регистрация | Undertale — Once Upon a Time (`public/music/once-upon-a-time.mp3`) |
| Вступительная катсцена, меню локаций | тревога, нарастает с первой сцены (синтез) |
| Подозреваемые, допросы | часы, перебор баса и колокольчик (синтез) |
| Место аварии | Undertale — Premonition (`public/music/premonition.mp3`) |
| Бокс №7 | механический остинато (синтез) |
| VIP-ложа | нуарный джаз (синтез) |
| Обвинение: ошибка | грустный вальс (синтез), доигрывает и на главной |
| Обвинение: дело раскрыто | сдержанная победная тема (синтез) |

Файлы Undertale в репозиторий не входят: положите их в `public/music/` под этими именами. Пока файла нет, вместо него звучит синтезированная замена. Браузер включает звук только после первого клика или нажатия клавиши.

```bash

```

## Стек

Vite + React 19 + TypeScript, react-router-dom, обычный CSS с токенами в `src/styles/tokens.css`. Пиксельный шрифт — Press Start 2P, текст — Montserrat (оба локально через `@fontsource`).

## Структура

```
src/
  api/        слой запросов: контракт с бэкендом, http-клиент, мок
  auth/       контекст авторизации (AuthProvider, useAuth, RequireAuth)
  components/ переиспользуемые блоки: PageShell, TrackBackdrop, Button, Field, AuthCard
  pages/      HomePage, LoginPage, RegisterPage, IntroPage, LocationsPage, LocationPage, SuspectsPage, InterrogationPage, AccusationPage
  cutscene/   движок катсцены, сценарии вступления и финала
  assets/     картинки: characters/ (листы ходьбы 96×128, ячейка 32×32), portraits/ (портреты 62×62 с эмоциями),
              locations/ (фоны локаций 320×180), cutscene/ (пятый механик и инженер)
  game/       болиды, фоны и свет катсцены, синтез звука, улики и подозреваемые, прогресс, поиск пути,
              characters.ts (отрисовка листов ходьбы), portraits.ts, locations/ (данные локаций)
  lib/        валидация форм
  styles/     токены и глобальные стили
  routes.ts   пути приложения
```

Маршруты: `/` — главная, `/login` — вход, `/register` — регистрация; только для авторизованных: `/intro` — катсцена, `/locations` — меню локаций, `/locations/:id` — локация, `/suspects` — выбор подозреваемого, `/suspects/:id` — допрос, `/accuse/:id` — обвинение.

## Подключение настоящего бэкенда

Пока `VITE_API_URL` не задан, работает мок в `localStorage` (`src/api/auth.mock.ts`): он повторяет ответы и ошибки будущего API. Как только появится сервер, достаточно положить адрес в `.env`:

```
VITE_API_URL=https://api.example.ru
```

и приложение само переключится на `src/api/auth.http.ts`. Сервер должен отдавать:

| Метод  | Путь             | Тело                      | Ответ                        |
| ------ | ---------------- | ------------------------- | ---------------------------- |
| `POST` | `/auth/register` | `{ nickname, password }`  | `{ token, user }`            |
| `POST` | `/auth/login`    | `{ nickname, password }`  | `{ token, user }`            |
| `GET`  | `/auth/me`       | —                         | `user`                       |
| `POST` | `/auth/logout`   | —                         | `204`                        |

Токен передаётся заголовком `Authorization: Bearer <token>`, формы ответов описаны в `src/api/types.ts`. Ошибки — обычные HTTP-коды с телом `{ "message": "текст для пользователя" }`.

По условию кейса регистрация идёт без почты и телефона — только никнейм и пароль.
